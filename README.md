# Hockey World Cup 2026

Static web version of the Hockey World Cup game.

## Publish with GitHub Pages
1. Create a GitHub repository.
2. Upload the contents of this folder to the repository root.
3. In **Settings → Pages**, choose **Deploy from a branch** and select `main` and `/ (root)`.
4. Save and wait for GitHub Pages to publish the site.

The entry point is `index.html`.

## Important
The current game is single-player/local-state. It is not real-time multiplayer. Adding online multiplayer would require a backend/realtime service and a shared game-state protocol.
